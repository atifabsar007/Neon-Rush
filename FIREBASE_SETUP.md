# NEON RUSH 0.5.0 — Firebase setup

The project now includes Firebase email/password authentication, anonymous guest authentication, Google Sign-In, password reset, Firestore cloud progress, and a global top-10 leaderboard.

## 1. Create Firebase project
1. Open https://console.firebase.google.com/ and create a project.
2. Add an Android app with package name **com.neonrush.game**.
3. Download `google-services.json` and place it in `android/google-services.json` (next to `android/build.gradle.kts`). Do not commit this file to a public repository unless you have reviewed the Firebase configuration and API restrictions.
4. In Firebase Authentication → Sign-in method, enable **Email/Password**, **Google**, and **Anonymous**.
5. In Project settings → Your apps, add SHA-1 and SHA-256 fingerprints for your debug/release signing keys. Google sign-in requires this.
6. Enable Cloud Firestore and create a database.

## 2. Firestore security rules
Publish these rules. They ensure users can only write their own player document while anyone can read leaderboard entries. For production, add App Check and abuse/rate limiting before public release.

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Private account/progression document: owner only.
    match /players/{uid} {
      allow read, create, update, delete: if request.auth != null && request.auth.uid == uid;
    }
    // Public leaderboard contains display name, score and level only — never email.
    match /leaderboard/{uid} {
      allow read: if true;
      allow create, update, delete: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

## 3. Build and test
Open the project in Android Studio, sync Gradle, then run the `android` configuration. The Google Sign-In client ID is generated by the Google Services Gradle plugin from `google-services.json`.

## Features
- Email/password account creation and login
- Google Sign-In (requires OAuth client + SHA fingerprints)
- Password reset email
- Firebase anonymous guest mode
- Firebase profile identity and logout
- Firestore cloud progress sync after each completed run
- Global leaderboard (top 10 by best score)
- Existing local game preferences remain on-device; the app restores the best score and progression counters from the signed-in player document on sign-in. Progress merges by taking the higher local/cloud values.

## Important
Never store passwords yourself. Firebase Authentication handles password storage and reset. Restrict your Firebase API key and configure Firestore rules before public release.
