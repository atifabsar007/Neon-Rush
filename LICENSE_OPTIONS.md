# Choose a License Before Adding `LICENSE`

No license has been selected on your behalf. A public GitHub repository is not automatically open source.

## Option A: MIT License

Choose this if you want to let others copy, modify, redistribute, and commercially use the code, as long as they preserve the required copyright and license notice. It does not require them to release modifications as open source. Add GitHub's official MIT template through **Add file > Create new file > LICENSE**, choosing `MIT License`, with the correct name/year.

## Option B: Apache License 2.0

A permissive license with explicit patent-related provisions and required license/notice handling. Appropriate when those terms are understood and wanted.

## Option C: No license yet

Keep the repository public for viewing and discussion, but do not add a `LICENSE` file until you decide to grant reuse rights. Note in the README that reuse permission has not yet been granted.

### Important

- Only license original materials you own or are authorized to release.
- Third-party dependencies remain governed by their own licenses.
- Do not publish private reference photos or signing credentials.
- License questions can affect how others may reuse the code; review the actual terms before deciding.
